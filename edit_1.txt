  ---
  Корневая причина (гипотеза)

  Большинство «пустых» результатов связано с одной проблемой: операции не могут разрезолвить короткое имя объекта в узел графа. При этом:
  - resolve_qn с полным qn — работает
  - resolve_qn_prefix — показывает дочерние узлы (включая атрибуты, измерения)
  - list_objects_by_name / list_objects_by_category — находят объекты

  Вероятно, внутренний lookup по имени в операциях list_attributes, list_dimensions, object_structure и т.д. сломан.

  ---
  Рекомендации

  1. Критично: Починить object_structure и все list_* операции, принимающие имя объекта
  2. Критично: Починить search_metadata_by_description — всегда пустой результат
  3. Высокий: Починить list_access_targets_of_role (ошибка Memgraph)
  4. Средний: Документацию CLAUDE.md привести в соответствие с реальным API (убрать list_http_services, list_event_subscriptions)
  5. Workaround: Пока можно использовать resolve_qn_prefix для получения структуры объектов — он работает и показывает дочерние узлы
