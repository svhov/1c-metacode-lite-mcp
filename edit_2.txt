  ---
  Критичные баги для исправления

  1. list_dimensions / list_resources — данные есть (видны через resolve_qn_prefix), но операции возвращают []
  2. object_structure — параметр "object" игнорируется, работает только "name"
  3. list_modules_of_owner — не фильтрует по owner, возвращает все модули
  4. list_access_targets_of_role — ошибка Memgraph
  5. list_callers_of_routine — всегда пустой (граф вызовов односторонний)

  Рекомендации для использования

  - Всегда использовать "name" вместо "object" для поиска объектов
  - Для измерений/ресурсов регистров — использовать resolve_qn_prefix как workaround
  - Для list_module_routines — передавать module_id с префиксом module:
  - Для list_callees_of_routine — работает как по id, так и по name
  - Для get_routine_body — использовать только id (из результатов find_routines_by_name)
