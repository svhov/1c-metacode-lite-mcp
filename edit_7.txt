Результаты find_usages_of_object

  Работает с target, name, object — все три ключа принимаются. Но результат некорректный:

  ┌───────────────────────────┬──────────────────┬──────────────────────────┬────────────────────────────────────────────────────────────────────┐
  │         Операция          │      Объект      │        Результат         │                              Проблема                              │
  ├───────────────────────────┼──────────────────┼──────────────────────────┼────────────────────────────────────────────────────────────────────┤
  │ find_usages_of_object     │ АМЕ_ВидыОпераций │ CONTAINS_OBJECT →        │ Возвращает родительскую категорию, а не объекты, которые           │
  │                           │                  │ Справочники              │ используют справочник                                              │
  ├───────────────────────────┼──────────────────┼──────────────────────────┼────────────────────────────────────────────────────────────────────┤
  │ find_usages_of_object     │ Контрагенты      │ CONTAINS_OBJECT →        │ То же самое                                                        │
  │                           │                  │ Справочники              │                                                                    │
  ├───────────────────────────┼──────────────────┼──────────────────────────┼────────────────────────────────────────────────────────────────────┤
  │ find_objects_using_object │ Контрагенты      │ HAS_ATTRIBUTE → ИНН,     │ Возвращает children (собственные реквизиты), а не объекты, которые │
  │                           │                  │ КПП...                   │  ссылаются на Контрагенты                                          │
  └───────────────────────────┴──────────────────┴──────────────────────────┴────────────────────────────────────────────────────────────────────┘

  Ожидаемое поведение:
  - find_usages_of_object("Контрагенты") должен вернуть объекты, у которых есть реквизит типа СправочникСсылка.Контрагенты (например,
  ДокументыПредприятия.Контрагент, АМЕ_АрхивДокументов.Контрагент)
  - find_objects_using_object("Контрагенты") — аналогично

  Фактическое поведение:
  - find_usages_of_object — идёт вверх по графу (к категории), а не ищет входящие ссылки
  - find_objects_using_object — идёт вниз по графу (к children), а не ищет исходящие ссылки

  Вывод: Обе операции не реализуют поиск по USE/REFERENCES-связям между объектами метаданных. Граф вызовов рутин (callers/callees) работает, а граф
  ссылок типов — нет.
